# 项目决策记录

## 2026-08-30：公开发布只保留两条正式路径

项目公开边界收敛为：

1. 音频/视频 → 制作音频 → 可选 Demucs 分离 → 一个 MIDI 后端 → MIDI → 黑白谱 → 彩色谱；
2. 简谱 → MIDI → 黑白谱 → 彩色谱。

旧 SkyStudio / 画世界 TXT 作为兼容入口保留，但不再扩展为第三条音频路线。旧多模型对比和一次性实验不随公开发布分支分发，必要时仅在本地或独立私有分支保存。

## 2026-08-30：Tsumugi 是默认吉他后端

Tsumugi `guitar_v1_5` 在 guitar stem 上作为默认路线；Basic Pitch、pYIN 和 torchcrepe 保留为可选后端。项目只调用一个用户选定的后端，不在正式入口自动运行多模型对比。Tsumugi 源码以 Git 子模块固定提交，权重由用户自行准备。

## 2026-08-30：MIDI 是可编辑中间层

音频识别结果不直接进入谱面。先生成 MIDI，用户可试听、编辑或替换 MIDI，再由唯一正式入口 `scripts/midi_to_sky.py` 生成黑白和彩色谱。这样可以把模型误差与谱面编排问题分开排查。

## 2026-08-30：彩谱只按不重叠规则压缩

同一时间的音符合为和弦；连续帧只有在与当前图所有已放入帧的按键集合都没有交集时，才合并为黑、红、蓝三层。出现交集就开启下一张逻辑图。时间信息不用于强行合并，但保存在 JSON 中供自动试听。

## 2026-08-30：公开仓库不收录本机产物

源码、测试、文档、小型示例和启动入口进入 Git。真实歌曲、音视频、MIDI/JSON/PNG 结果、模型权重、虚拟环境、日志和 Windows `.lnk` 均不进入公开仓库。Apache-2.0 是主项目许可证；第三方代码和模型按各自许可证处理。
