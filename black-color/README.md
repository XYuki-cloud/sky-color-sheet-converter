# Aurora Keys

`Aurora Keys` 是一个独立的原生 Android 应用，提供两个完全分离的入口：

- **黑白转彩谱**：把黑白 Sky 谱或结构化 TXT 转换为黑、红、蓝三层彩谱，并批量导出手机 PNG；
- **彩谱试听器**：导入黑白谱、彩谱或 TXT，按谱面层级实时合成声音并试听。

## 双入口

应用启动页只显示两个大卡片：

1. **黑白转彩谱**：进入转换器，负责导入、标题编辑、批处理和导出；
2. **彩谱试听器**：进入独立试听首页，负责导入和选择歌曲，不显示输出目录或转换按钮。

从转换器或试听首页进入播放页后，按返回会回到原列表，保留当前导入状态。转换器列表中的“试听”按钮也可直接打开播放页。

## 转换器

### 支持的输入

- `sky-black-v1` 黑白 JSON；
- UTF-8、UTF-8 BOM、UTF-16 编码的 SkyStudio/画世界结构化 JSON TXT；
- TXT 中的单首或多首歌曲；
- `Key0` 到 `Key14`，兼容带数字前缀的 `1Key0` 等按键写法。

已有 `sky-color-v1` 会被识别为“仅试听”，不会再次转换，也不会计入转换失败。损坏 JSON、缺少 `images`/`songNotes`、非法按键、非法时间和不支持的格式会留在列表中并显示具体原因；某一个文件出错不会阻塞其他任务。

### 标题与导出

每首歌曲默认使用原谱标题；原谱没有标题时使用文件名。标题可以逐首编辑，空标题会自动恢复默认值。自定义标题只写入 JSON 元数据和封面，不改变源文件名或结果目录基础名称。

每首歌曲输出一个独立目录：

```text
歌曲/
├── 歌曲.color.json
├── 歌曲.color-mobile-000.png   # 黄色标题封面
├── 歌曲.color-mobile-001.png   # 实际可播放谱页
└── 歌曲.color-mobile-002.png
```

连续且按键集合不重叠的源帧会按 **黑 → 红 → 蓝** 顺序放入同一张彩谱，每张彩谱最多三层，并保留 `source_frame_index` 和 `source_time`。如果输出目录已有同名结果，应用自动创建 `歌曲 (2)`、`歌曲 (3)` 等副本，不覆盖旧目录。

## 试听器

播放顺序固定为图片顺序，以及每张图片内的黑、红、蓝层顺序。播放页提供：

- 播放、暂停、停止、重新开始；
- 上一层、下一层和手动逐层试听；
- 15 键网格、当前图片、颜色层、图号、层号和时间显示；
- 依据 `source_time` 的自动播放和进度定位；
- 音量调节与 `-12` 到 `+12` 半音移调；
- 保持原音高的慢速自动播放。

### 倍速

自动播放提供以下预设：

```text
1×   1/2×   1/4×   1/5×   1/10×   1/20×   1/50×   1/100×
```

也可以用对数滑杆在 `1×` 到 `1/100×` 之间微调。倍速只拉长事件之间的播放间隔，保持原音高；音符本身的合成音长、移调映射和手动逐层试听不变。修改倍速时会重新锚定当前时间，不会跳到谱面其他位置。

如果任意彩谱层缺少有效 `source_time`，自动播放、进度定位和倍速控件会禁用，并显示“缺少有效 source_time，只能手动试听”；上一层、下一层、停止和手动试听仍可用。

试听声音由 Android `AudioTrack` 实时生成，不播放原曲音频，也不读取麦克风。使用三角波和高次泛音混合模拟单音/和弦，外部彩谱使用 JSON 中的调性，转换结果默认使用 C 调。

## 文件访问与隐私

应用通过 Storage Access Framework 选择文件或文件夹，并保存用户授予的 URI 权限：

- 不申请整机存储权限、录音权限或网络权限；
- 不上传输入文件、谱面、音频或播放数据；
- 文件夹模式只递归读取用户明确授权的目录；
- 输出只写入用户明确选择的目录；
- 不支持图片 OCR，不播放原曲音频，不提供后台锁屏播放。

## 构建

环境要求：JDK 17、Android SDK 35，以及 Windows PowerShell。工程自带 Gradle Wrapper，不需要全局安装 Gradle。

从仓库根目录执行：

```powershell
Set-Location .\black-color
.\gradlew.bat :app:testDebugUnitTest --offline --no-daemon
.\gradlew.bat :app:assembleDebug --offline --no-daemon
```

如果中文路径触发 Android Gradle Plugin 的路径处理问题，请把仓库复制到只含 ASCII 字符的目录后重试。Debug APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

提交前请运行单元测试、检查 `git diff --check`，并确认没有将本机路径、真实歌曲、生成 PNG、APK、日志或构建缓存提交到仓库。
